Jev at a glance

Modeljev-latest (Jev 1.13 at time of writing)
EndpointPOST https://api.typesafe.ai/v1/systemone
InputA state (text or structured data) plus a set of typed questions, evaluated in parallel
OutputTyped answers with per-option probabilities and a confidence score. No text generation.
Latency70 to 500 ms end to end, per TypeSafe
Pricing$0.042 per million input tokens, output free
SDKsJavaScript, Python, Vercel AI Gateway, community clients below

Choice

Pick one option from a list. Returns choice, probabilities, confidence.

Score

Rate the state on a numeric rubric. Returns score, probabilities, confidence.

Noul

Is this statement true? Returns noul, a probability from 0 to 1.

import { choice, TypeSafeClient } from "@typesafe-ai/sdk";

const client = new TypeSafeClient();
const response = await client.systemOne({
  state: { document: "I was charged twice. Please fix this ASAP." },
  questions: {
    category: choice("What is this ticket about?", {
      billing: null,
      technical: null,
      other: null,
    }),
  },
});

console.log(response.answers.category.choice);
