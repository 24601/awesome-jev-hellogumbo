Decisions, not text.

Send Jev a block of state and a set of typed questions. It answers all of them in parallel, in roughly 70 to 500 ms, and returns values your code can branch on. Three primitives cover most of it.

Choice

Pick one option from a list. Returns the choice, a probability per option, and confidence.

Score

Rate the state against a rubric. Returns the score, a distribution, and confidence.

Noul

Is this statement true? Returns a single probability between 0 and 1.
